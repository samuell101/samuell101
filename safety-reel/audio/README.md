# Voiceover placeholder

No narration is synthesized. Record the script below and save it here as
**`voiceover.mp3`** (or change `voiceover.src` in `js/config.js`).

* The preview plays it in sync with the timeline (or use **Load narration file** in the panel).
* `node tools/render.js` mixes it over the sound effects automatically.
* `voiceover.offset` (seconds) shifts it; `voiceover.volume` sets its level.
